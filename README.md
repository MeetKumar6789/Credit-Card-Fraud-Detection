## 📖 Project Overview
This project focuses on detecting fraudulent credit card transactions using Data Science and Machine Learning techniques. The main objective is to build a model that can reliably classify transactions as **genuine** or **fraudulent** based on transaction data.

Credit card fraud detection is an important real-world application of Machine Learning in the finance industry.

## 🛠️ Technologies Used
* **Python** 🐍
* **Pandas** & **NumPy** 📊 (Data Manipulation)
* **Matplotlib** & **Seaborn** 📈 (Data Visualization)
* **Scikit-learn** 🤖 (Machine Learning)
* **Google Colab** 📓

## 📊 Dataset Information
The dataset contains transaction details of credit card payments. It includes both genuine and fraudulent transactions.

The target column used for prediction is `Class`:
* `0` → Genuine Transaction ✅
* `1` → Fraudulent Transaction 🚨

## 🧠 Machine Learning Model
* **Random Forest Classifier** was used for training and prediction.
* The model was trained to identify fraudulent transactions based on intricate transaction features.

## ⚙️ Data Preprocessing
The following preprocessing steps were performed:
* Handling missing values
* Feature selection
* Train-test splitting
* Data visualization

## 📈 Data Visualization
Different visualizations were created to better understand the dataset and transaction patterns, including:

## 📏 Evaluation Metrics
The model performance was evaluated using multiple metrics:
